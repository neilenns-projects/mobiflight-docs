---
title: Padding
description: How to use the padding modifier to change input values in MobiFlight.
---

The padding modifier adds additional characters to the input value to ensure it is always the specified length.

The **Lenght** field specifies how long the padded string will be. The **Character** field specifies the character to pad with. The **Direction** field specifies whether the padding characters are added to the left or right of the input value.
