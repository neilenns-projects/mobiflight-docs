MobiFlight supports several different methods to map inputs to a flight simulator control. While there are many options available, the most commonly used are:

- [Microsoft Flight Simulator (All Versions)](/features/input-action-types/microsoft-flight-simulator/), for controlling aircraft in Microsoft Flight Simulator 2020 and 2024.
- [X-Plane (all versions)](/features/input-action-types/x-plane-all-versions/), for controlling aircraft in all versions of X-Plane.
- [MobiFlight - Variable](/features/input-action-types/mobiflight-variable), for setting variables used in [preconditions](/features/preconditions/).

The list of action types displayed is filtered by the simulator and options selected in the [Project settings](/features/projects/#provide-the-project-settings). For example, when working in a Microsoft Flight Simulator project, the X-Plane action types will not be displayed.

The other action types are only used in the specific situations, described on the associated reference page.
